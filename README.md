## 첫 화면
- **건물 설계**: 전원주택·주택·빌라, 1~5층
- **공간 리모델링**
  - **도면 파일로 시작**: DWG·DXF를 불러와 벽·문 레이어만 남기고, 2D에서 방을 끌어 지정한 뒤 가구 배치
  - **치수로 시작**: 전체 가로·세로와 공간별 크기를 넣어 새 평면, 복층까지

## 건물 설계 순서
1. **집 종류·외관**: 집 종류(렌더링 주변이 바뀜: 전원주택=산·잔디·나무, 주택·빌라=도로·골목·반투명 이웃 건물), 지붕, 외장재 16종, 지붕재 7종, 실내 높이, 데크
2. **층수·크기·계단**: 1~5층, 층별 평수(숫자 입력, 최대 50평)와 가로(mm) → 세로 자동, 계단 ㄷ자·ㄴ자·일자·원형 (자리가 모자라면 경고)
3. **층별 공간**: 거실·주방(일자/ㄱ자/ㄷ자/아일랜드)·다이닝 유무와 크기, 안방·침대방·그외 방·화장실(독립/방 귀속)·드레스룸(독립/방 귀속)·다용도실·팬트리 개수, 공간마다 가로×세로(mm). 거실·복도는 남는 공간으로 자동, 모자라면 몇 mm가 더 필요한지 알려 줍니다.
4. **가구**: 공간마다 흔히 쓰는 가구가 크기와 함께 나와 고르기만 하면 됩니다. 붙박이장·책장·소파처럼 사이즈를 정해야 하는 가구는 크기를 넣습니다. 안 들어가면 이유와 함께 표시하고, 문에서 가구 앞까지 폭 500mm 이상 동선을 확인합니다.
5. **문**: 공간마다 여닫이/미닫이/문 없음, 폭 700~900mm(50mm 단위). 현관문 900~2000mm(1500 이상 양개), 중문(3연동 슬라이딩). 문 없음이면 그 폭만큼 통로, 주방·다이닝·거실을 모두 문 없음으로 두면 사이 벽 없이 트입니다.

**도면 만들기**를 누르면 그리기 전에 문제 목록이 뜨고, 버튼이나 직접 입력으로 바로 고칠 수 있습니다.

## 5.1에서 바뀐 점
- **새로 시작**: 위쪽 ‘새로 시작’을 누르면 모든 내용이 비워집니다. 처음 화면에서 시작해도 빈 상태입니다. ② 층수·크기에서 **평수+가로** 또는 **가로+세로**를 넣는 순간 평면(외벽)이 생기고, ③에서 현관·거실·주방·방을 하나씩 켜거나 더하면 빈 자리에 블록으로 놓입니다. ‘예시로 채우기’로 20평 예시를 불러올 수도 있습니다.
- **문 위치**: 배치 편집에서 공간마다 보이는 빨간 점(●)을 벽을 따라 끌면 문이 그 자리로 갑니다. ⑤ 문에서 위쪽·아래쪽·왼쪽·오른쪽 벽을 골라도 됩니다. 바깥벽이나 열린 공간 쪽은 문을 낼 수 없어 자동 위치로 돌아가며 안내가 나옵니다.
- **주방 방향**: ③ 공간의 주방에서 조리대가 붙는 쪽(위·아래·왼쪽·오른쪽)을 고릅니다. 일자·ㄱ자·ㄷ자·아일랜드 모두 그 벽을 기준으로 돌아갑니다.
- **계단**: 어떤 형태든 올라가기 시작하는 곳(아래·위·왼쪽·오른쪽)과 도는 방향을 고를 수 있고, 한 계단 폭을 900~1,200mm(50mm 단위)에서 고릅니다. 한 단 높이는 층높이를 180mm 이하로 나눈 값, 한 단 길이(단너비)는 260mm를 기본값으로 씁니다(공동으로 쓰는 계단 기준).
- **가구 위치**: 배치 편집에서 가구(점선 사각형)를 끌어 옮기고, 선택한 뒤 ‘가구 돌리기’(또는 두 번 누르기)로 90°씩 돌립니다. ‘자동 위치’를 누르면 그 가구만 자동 배치로 돌아갑니다. 붙박이인 주방 조리대(방향 선택)와 욕실 기구, 신발장은 자동입니다.

## 5.0에서 바뀐 점
- **배치 편집 (블록 끌어 놓기)**: 2D 평면도 위 **배치 편집**을 누르면 방·화장실·드레스룸·주방·다이닝·거실·현관·계단·엘리베이터가 블록으로 보입니다. 블록을 끌어 옮기고, 모서리를 끌어 크기를 바꿉니다(100mm 단위, 벽·다른 블록 가장자리에 자석처럼 붙음). 휴대폰에서도 손가락으로 끌 수 있습니다.
  - 순서(③ 공간 배치 목록 ▲▼)가 우선순위입니다. 앞 블록이 크기를 지키고, 겹치거나 평면 밖으로 넘치면 **그 블록을 줄여 맞추고**, 더 놓을 자리가 없으면 **반영하지 않고 경고**를 띄웁니다(빨간 점선).
  - ‘채움’에 체크한 블록(기본: 거실)은 남은 빈 자리를 모두 씁니다. 블록이 없는 빈 곳은 복도·홀이 됩니다.
  - 벽은 블록 경계에 자동으로 생기고, 거실·주방·다이닝·계단처럼 열린 공간끼리는 벽 없이 트입니다. 문은 복도·거실에 맞닿은 벽에 자동으로 납니다.
  - 계단·엘리베이터 블록은 모든 층이 같은 자리를 씁니다. **자동으로 되돌리기**로 언제든 처음 배치로 돌아갑니다.
- **휴대폰 화면 오류 수정**: 결과 탭에서 2D·3D·렌더링이 안 보이던 문제를 고쳤습니다.
- **도심 렌더링**: 앞 도로(10m)·골목(6m)·보도를 넓히고, 이웃 건물을 더 투명하고 조금 작게, 더 멀리 두었습니다.

## 4.1에서 바뀐 점
- **빌라 층당 1~2세대**: 2세대를 고르면 가운데 공용 계단실을 두고 좌우 대칭(미러)으로 배치합니다. 한 세대만 꾸미면 다른 세대는 자동으로 대칭입니다. 세대 크기는 모든 층이 같습니다.
- **계단은 세대 밖**: 빌라 계단은 세대를 나와 가운데 복도(계단실) 북쪽에 있고, 각 세대 현관문은 이 복도 쪽으로 납니다. 1층은 공동현관, 필로티 주차도 고를 수 있습니다.
- **엘리베이터**: 주택·빌라 모두 4층 이상이면 자동으로 들어갑니다(1,900×2,100). 빌라는 계단실 안 계단 앞, 주택은 계단 옆입니다. 자리가 모자라면 그리기 전 확인에서 알려 줍니다.

## 내보내기
| 결과 | 파일 | 원하는 형식으로 바꾸는 법 |
|---|---|---|
| 2D 도면 | DXF (한 장씩 / 전체 한 번에) | 무카 CAD·AutoCAD에서 열고 ‘다른 이름으로 저장 → DWG’ |
| 3D 모델 | 스케치업 스크립트(.rb), DAE, OBJ | 스케치업 Ruby 콘솔에서 .rb를 load → 모델 생성 → .skp 저장 |
| 렌더링 | PNG(2배 해상도), GLB | 언리얼 엔진 5에서 Import로 GLB를 바로 엽니다 |

## AI 모드와 무카 CAD (리모델링)
- **AI 모드**: 프로젝트·설정에서 본인 Anthropic API 키를 넣으면, AI가 공간마다 가구를 고르고 프로그램이 배치·동선을 검사합니다.
- **무카 CAD와 함께**: ‘무카 CAD로 보내기’를 누르면 벽·문 DXF와 요청 문장이 준비됩니다. Claude(무카 CAD 연결)에게 붙여 넣어 가구를 그리게 하고, 결과 DXF를 ‘가구 도면 불러오기’로 다시 넣으면 2D·3D·렌더링에 반영됩니다.

## 알아두실 점
- DWG 읽기는 깃허브 주소에서 동작합니다(처음 한 번 해석 프로그램 약 12MB 내려받음, LibreDWG/GPL-3.0 기반). 미리보기 화면에서는 DXF만 됩니다.
- DWG·SKP·언리얼 전용 파일(.uasset)을 브라우저에서 직접 쓰는 공개 방법이 없어, 위 표처럼 각 프로그램이 바로 여는 형식으로 내보냅니다.
- 로그인은 남이 쉽게 쓰지 못하게 막는 잠금 장치이며 서버 보안 수준은 아닙니다.
