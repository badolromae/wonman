# 원만하다 7.2

원하는 대로 만들고, 하려는 것 다 하자.
**버튼을 끌어다 평면에 놓고, 손이나 숫자로 다듬는** 건물·인테리어·공간 설계 프로그램입니다.

## 깃허브에 올리기
1. 저장소의 `index.html`을 이 파일로 바꿉니다.
2. Settings → Pages → Branch: main / (root)
3. 처음 로그인: `wonman` / `wonman2026!` (계정을 바꿔 쓰셨다면 `const CRED` 줄을 다시 붙여 넣으세요)

## 처음 화면 (그림 버튼 3개)
- **건물 만들기**: 집 종류 → 층수(빌라는 세대 수·필로티) → 크기(평수+가로 또는 가로+세로) → 계단(형태·폭·시작점) → 외장재 → 지붕 → 높이를 한 화면씩 고른 뒤 평면으로 갑니다. 평면에서 위쪽 **🏠 건물 설정**으로 언제든 다시 바꿀 수 있습니다.
- **인테리어 하기**: 한 개 층 평면도(DWG·DXF)만 들어 있는 파일을 올리면 벽 레이어만 남기고, 욕실·화장실 글자나 기호를 찾아 욕실을 미리 넣은 뼈대에서 시작합니다. 남길 레이어는 직접 바꿀 수 있습니다.
- **공간 꾸미기**: 가로·세로와 복층 유무(복층 크기)만 넣고 바로 평면으로 갑니다.

## 평면에서 하는 일
- **공간 넣기**: 왼쪽(휴대폰은 아래) 공간 버튼(거실·주방·다이닝·안방·침대방·그외 방·화장실·드레스룸·다용도실·팬트리·현관)을 평면으로 끌어다 놓습니다. 누르기만 하면 빈 자리에 놓입니다.
- **공간 다듬기**: 공간을 누르면 그 공간만 선택되고 오른쪽(휴대폰은 아래) 창이 열립니다.
  - **📐 크기**: 가로·세로를 큰 칸에 넣거나, 도면에서 공간 안을 끌어 옮기고 변의 네모로 크기를 바꿉니다. 변을 두 번 누르면 꺾인 모양, ‘⬜ 사각형으로’로 되돌립니다.
  - **🪑 가구**: 가구를 고르고, 도면에서 그 공간 가구를 끌어 옮기고 두 번 눌러 돌립니다.
  - **🚪 문**: 문 종류·폭을 고르고, 도면에서 그 공간 벽을 누르면 그 자리로 문이 옮겨집니다.
- **겹치지 않게**: 공간을 옮기거나 키울 때 다른 공간과 겹치면 그 앞에서 멈춥니다. 선택하지 않은 공간은 끌리지 않습니다.
- **계단·엘리베이터**: 계단을 누르면 형태·폭·시작점을 바꾸고, 끌면 모든 층 계단이 같이 옮겨집니다. 계단은 실제 쓰는 모양만 차지합니다.
- **복층**: 복층 층에서 ‘복층 꾸미기’를 누르고 복층을 끌어 원하는 곳에 둡니다. 복층은 높이 1,200mm라 방 없이 가구만 놓고, 계단과는 계단참으로 이어지며, 바깥벽에 닿지 않는 가장자리는 난간이 섭니다. 1층 벽과 계단은 점선으로 보입니다. 바깥벽은 복층 높이까지 올라가 밖에서 보면 한 덩어리로 보입니다.
- **📏 거리**: 첫 점을 찍은 뒤 가로·세로(90° 방향)로만 재어집니다.

## 7.2에서 바뀐 점
- **계단은 실제 모양만 차지**: ㄴ자는 ㄴ자 모양, 원형은 원에 가까운 모양만 막고 나머지 모서리는 다른 공간이 들어올 수 있습니다(끌어 옮길 때도 실제 모양으로 부딪힘을 봅니다).
- **계단 아래 2,000mm 이상은 다른 공간 가능**: 계단 아래 높이(디딤판 두께 250mm를 뺀 값)가 2,000mm 이상인 부분은 점선으로 표시되고, 팬트리·수납·화장실 같은 공간을 겹쳐 넣을 수 있습니다. 진한 부분은 낮아서 넣을 수 없습니다.
- **오르는 방향 반대로**: 계단을 고른 뒤 ‘⇅ 같은 자리에서 오르는 방향 반대로’를 누르면 계단 모양·자리는 그대로 두고 올라가는 시작점과 끝점만 바뀝니다(ㄴ자는 짧은 쪽부터 오르게 바뀝니다). ‘↔ 도는 방향 반대로’도 따로 있습니다.

## 7.1에서 바뀐 점
- **복층 아래 내벽**: 1층 칸막이벽이 복층 바닥 아래(복층 바닥 높이)까지만 올라가 복층을 뚫지 않습니다. 바깥벽은 그대로 복층 높이까지 올라갑니다.
- **공간 꾸미기 복층 계단**: 복층이 있으면 1층에 계단 블록이 자동으로 생깁니다. 계단을 눌러 형태·폭·시작점을 바꾸고 끌어 옮깁니다.
- **문 열리는 방향**: 🚪 문 탭에서 왼쪽 경첩 / 오른쪽 경첩, 안쪽 / 바깥쪽으로 열림을 고릅니다.
- **신발장 이동**: 현관을 고르고 🪑 가구 탭에서 신발장을 끌어 옮기고 두 번 눌러 돌립니다.
- **층별 3D·렌더링**: 3D·렌더링에서 위쪽 [전체][1층][복층·2층…]을 누르면 그 층만 보입니다.
- **렌더링 가구**: 3D는 각진 상자 그대로, 렌더링에서는 침대(헤드보드·베개·이불), 소파(쿠션·팔걸이·쿠션·다리), TV장, 소파 테이블, 식탁·의자, 책상·모니터, 붙박이장(문·손잡이), 협탁·스탠드, 주방(하부장·상판·상부장·손잡이), 냉장고, 변기·세면대·샤워부스·욕조, 화분, 옷걸이 등을 둥근 모서리와 세부 모양으로 그립니다. 그림자 해상도와 화면 선명도도 올렸습니다.
- **🎨 색 테마**: 위쪽 ‘🎨 색’에서 색 하나를 고르면 벽·소파·침구·러그·의자·쿠션을 그 색 계열로 꾸밉니다. ‘단색 계열’은 비슷한 색으로, ‘어울림’은 포인트 색을 섞습니다. 12가지 추천 색과 직접 고르기가 있습니다.
