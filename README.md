# 원만하다

원하는 대로 만들고, 하려는 것 다 하자.
문장 한 줄이나 버튼 선택으로 **2D 도면(층별 평면도·입면도 4면) → 3D 모델 → 렌더링**까지 만드는 개인용 웹 프로그램입니다.
기본 분석은 AI 없이 브라우저 안에서 동작하고, 원하면 본인 API 키로 AI 분석을 켤 수 있습니다.

## 깃허브에 올리기
1. 깃허브에서 새 저장소를 만듭니다 (예: `wonman`).
2. 이 폴더의 `index.html`을 저장소에 올립니다. (파일 하나만 있으면 됩니다)
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://아이디.github.io/wonman/` 으로 들어갑니다.

## 처음 로그인
- 아이디: `wonman`
- 비밀번호: `wonman2026!`

**처음 들어가면 바로 바꾸세요.** 앱의 `프로젝트·설정 → 계정 바꾸기`에서 새 아이디·비밀번호로 코드 한 줄을 만든 뒤,
깃허브의 `index.html`에서 `const CRED = /*CRED*/{ ...` 로 시작하는 줄을 그 줄로 통째로 바꿔 커밋합니다.

## 알아두실 점
- 비밀번호는 원문 대신 PBKDF2(SHA-256, 12만 회) 해시만 파일에 들어갑니다. 다만 깃허브 Pages는 정적 사이트라서
  **로그인은 남이 쉽게 쓰지 못하게 막는 잠금 장치**이지, 서버 보안 수준은 아닙니다. 회사 기밀 도면은 올리지 마세요.
- 공개 저장소면 코드 자체는 누구나 볼 수 있습니다. 비공개 저장소로 Pages를 쓰려면 깃허브 유료 요금제가 필요합니다.
- 프로젝트는 각 기기의 브라우저에 저장됩니다. 기기 간 이동은 `프로젝트·설정 → 모두 파일로 내보내기 / 파일에서 가져오기`를 쓰세요.
- 인터넷 연결은 처음 3D 화면을 열 때(three.js 불러오기)와 글꼴에만 필요합니다.

## 내보내기
| 화면 | 파일 |
|---|---|
| 2D 도면 | 층별 평면도·입면도 DXF (무카 CAD·AutoCAD), SVG, PNG, 인쇄·PDF |
| 3D 모델 | DAE (스케치업: 파일 → 가져오기), OBJ + MTL, PNG |
| 렌더링 | 2배 해상도 PNG |

## 문장 예시
- `15평 박공지붕 전원주택, 방 2개 욕실 1개 팬트리, 실내높이 3미터, 데크. 방 하나는 슈퍼싱글 침대 두 개에 붙박이장, 다른 방은 슬라이딩도어에 책상 두 개`
- `32평 2층 단독주택, 방 4개, 안방은 킹침대에 협탁 두개 화장대, 안방 드레스룸과 전용 욕실, 아이방은 슈퍼싱글 침대와 책상, 주방 팬트리`
- `5층 빌라, 1층 필로티 주차, 세대 25평 방 3개 욕실 2개, 적벽돌 외벽`
- `6평 평지붕 농막, 화장실, 데크, 노출 콘크리트`
- `가로 12m 세로 7m 외쪽지붕 세컨하우스, 방 1개, 징크 외벽, 경사 12도`

## 2.0에서 바뀐 점
- **1~5층**: 단독주택은 층마다 방을 나누고 계단(ㄷ자)을 넣습니다. 빌라는 계단실 + 층마다 세대, 1층 필로티 주차를 고를 수 있습니다.
- **면적 5~50평**: 주택은 전체 연면적, 빌라는 한 세대 면적입니다.
- **방 개수 상한**: 한 층 면적에서 거실·주방·현관·욕실 약 5평을 빼고, 방 하나에 약 4.5평으로 계산합니다. (15평 2개, 24평 4개, 50평 8개 등)
- **방 종류**: 안방 / 침대방 / 그외 방. 안방·침대방에는 드레스룸과 전용 욕실을 붙일 수 있습니다. (방 → 드레스룸 → 욕실 순서로 이어짐)
- **팬트리 위치**: 현관 쪽 또는 주방 쪽
- **가구 목록**: 기본 28종 + 내가 추가한 가구 (CSV로 한꺼번에 가져오기 가능). 문장에서 이름·같은 말로 알아듣습니다.
- **배치 검사**: 가구를 벽에 붙여 자동 배치하고, 못 넣으면 이유(방보다 큼, 문 열리는 자리와 겹침, 앞쪽 사용 공간 부족, 창문을 막음 등)를 보여 줍니다. 문에서 각 가구 앞까지 폭 500mm 이상 길(동선)이 있는지 확인해 도면에 점선으로 그립니다.
- **골라서 만들기**: 글을 쓰지 않고 버튼으로 건물·층수·면적·지붕·방·욕실·팬트리·마감을 골라 만들 수 있습니다.
- **AI 분석(선택)**: 프로젝트·설정 → AI 분석에서 Anthropic API 키를 넣고 켭니다. 실패하면 기본 분석으로 바로 만듭니다.

## 아직 안 되는 것
- 층마다 외곽 크기가 다른 집, 곡선 벽, 자유 평면
- 빌라 층당 2세대 이상
- 가구를 도면에서 직접 끌어 옮기기
