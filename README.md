# 원만하다

원하는 대로 만들고, 하려는 것 다 하자.
문장 한 줄로 **2D 도면(평면도·입면도 4면) → 3D 모델 → 렌더링**까지 만드는 개인용 웹 프로그램입니다.
AI 없이 브라우저 안에서 규칙 기반으로 문장을 분석하고 도면을 그립니다.

## 깃허브에 올리기
1. 깃허브에서 새 저장소를 만듭니다 (예: `wonman`).
2. 이 폴더의 `index.html`을 저장소에 올립니다. (파일 하나만 있으면 됩니다)
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://아이디.github.io/wonman/` 으로 들어갑니다.

## 처음 로그인
- 아이디: `wonman`
- 비밀번호: `wonman2026!`

**처음 들어가면 바로 바꾸세요.** 앱의 `프로젝트·설정 → 계정 바꾸기`에서 새 아이디·비밀번호로 코드 한 줄을 만든 뒤,
깃허브의 `index.html`에서 `const CRED = /*CRED*/{ ...` 로 시작하는 줄을 그 줄로 통째로 바꿔 커밋합니다.

## 알아두실 점
- 비밀번호는 원문 대신 PBKDF2(SHA-256, 12만 회) 해시만 파일에 들어갑니다. 다만 깃허브 Pages는 정적 사이트라서
  **로그인은 남이 쉽게 쓰지 못하게 막는 잠금 장치**이지, 서버 보안 수준은 아닙니다. 회사 기밀 도면은 올리지 마세요.
- 공개 저장소면 코드 자체는 누구나 볼 수 있습니다. 비공개 저장소로 Pages를 쓰려면 깃허브 유료 요금제가 필요합니다.
- 프로젝트는 각 기기의 브라우저에 저장됩니다. 기기 간 이동은 `프로젝트·설정 → 모두 파일로 내보내기 / 파일에서 가져오기`를 쓰세요.
- 인터넷 연결은 처음 3D 화면을 열 때(three.js 불러오기)와 글꼴에만 필요합니다.

## 내보내기
| 화면 | 파일 |
|---|---|
| 2D 도면 | DXF (무카 CAD·AutoCAD), SVG, PNG, 인쇄·PDF |
| 3D 모델 | DAE (스케치업: 파일 → 가져오기), OBJ + MTL, PNG |
| 렌더링 | 2배 해상도 PNG |

## 문장 예시
- `15평 박공지붕 전원주택, 방 2개 욕실 1개 팬트리, 실내높이 3미터, 데크. 방 하나는 슈퍼싱글 침대 두 개에 붙박이장, 다른 방은 슬라이딩도어에 책상 두 개`
- `24평 모임지붕 단독주택, 방 3개 욕실 2개, 드레스룸, 적벽돌 외벽, 기와 지붕`
- `6평 평지붕 농막, 화장실, 데크, 노출 콘크리트`
- `가로 12m 세로 7m 외쪽지붕 세컨하우스, 방 1개, 징크 외벽, 경사 12도`

## 현재 범위 (1.0)
- 1층 단층, 5~60평, 방 0~4개, 욕실 0~2개
- 지붕: 박공·모임·외쪽·평지붕 / 외벽 5종 / 지붕재 4종
- 2층·곡선 벽·자유 평면은 다음 버전에서 다룹니다.
